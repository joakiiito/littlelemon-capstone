Welcome to Little Lemon

This page is served by Django. The REST API for this project is available under the following paths:

  • /api/menu/ — browsable API for menu items
  • /api/bookings/ — browsable API for table bookings (requires authentication)
  • /api-token-auth/ — obtain a DRF auth token
  • /auth/users/ — djoser: register a new user
  • /auth/token/login/ — djoser: obtain an auth token
  • /admin/ — Django admin
