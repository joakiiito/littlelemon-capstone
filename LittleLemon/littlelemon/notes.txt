LITTLE LEMON BOOKING SYSTEM - SETUP NOTES
==========================================

Project directory: littlelemon
App: restaurante
Database: MySQL

SETUP
-----
1. Create the MySQL database (name used in settings.py is "reservations"):
       mysql -u root -p
       CREATE DATABASE reservations;

2. Open littlelemon/settings.py and set your local MySQL credentials in DATABASES:
       'USER': 'root',
       'PASSWORD': 'YOUR_MYSQL_PASSWORD',   <-- change to your MySQL password
       'HOST': '127.0.0.1',
       'PORT': '3306',
   (Username/password will vary depending on your local machine.)

3. Create the virtual environment and install dependencies:
       cd littlelemon
       pipenv shell
       pipenv install
       # (installs Django and mysqlclient)

4. Run migrations and start the server:
       python manage.py makemigrations
       python manage.py migrate
       python manage.py runserver

PAGES
-----
  /              Home page (Little Lemon website)
  /about/        About page
  /book/         Booking form (Name, Booking date, Booking slot)
                 - date field opens a date picker
                 - current date is auto-selected on load
                 - already-booked slots are greyed out (no duplicates)
                 - uses the fetch API to load/save bookings
  /reservations/ All bookings shown as JSON data
  /bookings/     API endpoint:
                   GET  /bookings/?date=YYYY-MM-DD  -> JSON of bookings for that date
                   POST /bookings/ (JSON body)      -> creates a booking,
                                                       returns {"error":1} if the
                                                       date+slot is already taken
  /admin/        Django admin (create a superuser to view Booking records)

FEATURES COVERED
----------------
- restaurante app added to INSTALLED_APPS
- MySQL database configured in settings.py
- Migrations included
- Booking form with 3 fields: Name, Booking date, Booking slot
- Date picker on the booking date field
- Current date auto-selected when the form opens
- All bookings available as JSON on /reservations/
- Bookings for a specific date via API (/bookings/?date=...)
- "No bookings for that date" message when empty
- Duplicate booking (same date + slot) is prevented (DB unique_together + view check)
- Changing the date refreshes the booking data
- fetch API used to retrieve/save data
